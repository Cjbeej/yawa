Travel Fare Calculator

Description

This Python program calculates the total fare for passengers based on the travel distance and number of passengers. The fare rate is PHP 14 per kilometer per passenger.

Version 1 - Original Code Without Input Validation

Input: Accepts the passenger's name, travel distance in kilometers, and number of passengers.

Process: Multiplies the distance by the fare rate of PHP 14 and the number of passengers.

Output: Displays the passenger's name and total fare rounded to two decimal places.

Validation: Does not include input validation.

Version 2 - Improved Code With Input Validation

Input: Accepts the passenger's name, travel distance, and number of passengers.

Process: Checks that the passenger's name is not empty, the distance is a number greater than 0, and the number of passengers is a positive whole number. Invalid inputs display an error message and ask the user to re-enter the input.

Output: Displays the passenger's name and the total fare in Philippine pesos, rounded to two decimal places.

Validation: Includes input validation to prevent empty names, non-positive distances, and invalid passenger counts.

Version History

Version 1: Original program without input validation.

Version 2: Added input validation, error messages, and input re-entry for invalid inputs.
